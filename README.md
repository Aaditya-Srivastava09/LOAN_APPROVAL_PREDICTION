# LOAN_APPROVAL_PREDICTION
🏦 Loan Prediction Model
A machine learning project built in Python that predicts whether a loan application will be approved or rejected based on applicant details.
🎯 About the Project
This is one of my ML projects as a first-year B.Tech AI/ML student. I built this to get hands-on experience with:

Real-world dataset handling and preprocessing
Training and evaluating a classification model
Understanding features that affect loan approval decisions

🛠️ Tech Stack

Language: Python 3
Libraries: Pandas, NumPy, Scikit-learn, Matplotlib/Seaborn
Deployment: Streamlit Community Cloud

⚙️ How It Works

Takes applicant input — income, loan amount, credit history, employment status, etc.
Preprocesses the data (handles missing values, encodes categorical variables)
Passes it through a trained classification model (e.g. Logistic Regression / Decision Tree)
Predicts Loan Approved ✅ or Loan Rejected ❌

🚀 How to Run Locally
bashpip install -r requirements.txt
streamlit run app.py
